建立公開 GitHub 網頁專案
1. GitHub 右上角 + → New repository。
2. Owner 選 viclinviclin-eng。
3. Repository name 填 viclinviclin-eng.github.io。
4. Public，勾 Add a README file，Create repository。
5. 在新專案 Add file → Upload files，上傳此 ZIP 解壓後的內容。
   index.html、privacy.html、support.html、app-ads.txt 必須在根目錄，不是子資料夾。
   一起上傳 style.css、language.js、assets 資料夾與 .nojekyll。
6. Commit changes。
7. Settings → Pages → Source: Deploy from a branch → Branch: main / (root) → Save。
8. 發布後逐一確認：
   https://viclinviclin-eng.github.io/
   https://viclinviclin-eng.github.io/privacy.html
   https://viclinviclin-eng.github.io/support.html
   https://viclinviclin-eng.github.io/app-ads.txt
這些是預期網址，尚未建立或驗證；等可公開開啟後再填入遊戲與 Apple。
